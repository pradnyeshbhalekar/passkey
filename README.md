# 🔐 PassKey – Secure Credential Management System

PassKey is a security-focused credential management system designed to help users securely store, manage, and generate passwords. The application demonstrates practical cybersecurity concepts such as encryption, authentication, access control, and secure credential storage through a modern full-stack web application.

## 🌐 Live Demo

https://passkey-ftx3.onrender.com

## 📂 Repository

https://github.com/pradnyeshbhalekar/passkey

---

## 🚀 Features

### 🔑 Secure Authentication

* Google OAuth Login
* Secure user authentication flow
* Session-based access management

### 🔒 Password Vault

* Store credentials securely
* Add, edit, and delete passwords
* Search and organize stored accounts
* Copy credentials quickly when needed

### ⚡ Password Generator

* Generate strong passwords instantly
* Customizable password length
* Support for uppercase, lowercase, numbers, and special characters

### 🛡️ AES Encryption

* Sensitive password data is encrypted before storage
* Helps protect credentials from unauthorized access
* Demonstrates implementation of cryptographic security controls

### 📱 Responsive User Experience

* Clean and intuitive interface
* Mobile-friendly design
* Modern security-focused dashboard experience

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/pradnyeshbhalekar/passkey.git
cd passkey
```

### Frontend Setup

```bash
cd frontend
npm install
npm start
```

### Backend Setup

```bash
cd backend
npm install
npm start
```
